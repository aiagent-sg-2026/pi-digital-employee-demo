# Digital Employee — GitHub Social Preview Specification

## Current asset

`public/social-preview.png` is a real 1200×630 capture of the deployed Digital Employee Home page. It is suitable as an honest Open Graph fallback and contains no fabricated product state.

## Future custom banner direction

Canvas: **1200×630**, light theme.

Visual hierarchy:

1. **Digital Employee**
2. “Browser-first verified business work”
3. Three trust concepts: **Human approval · Deterministic verification · Evidence**
4. A clean crop or reconstruction of the real product workspace showing Alex, the task composer, KPI cards and verification status.

Style:

- professional,
- operational,
- calm,
- enterprise-ready,
- light neutral background,
- subtle borders,
- real product typography and SVG icon language.

Avoid:

- cyberpunk / neon AI glow,
- robot or humanoid AI imagery,
- generic code screenshots,
- fake ERP/Gmail connection states,
- claims of autonomous external writes.
